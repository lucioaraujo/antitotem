Sound Object

Standalone JUCE/C++20 modular instrument, precursor and patron of the RASGO family. Five oscillators, 16-step scanner, ADSR, multimode VCF, noise and S&H, feedback sends, effects, mixer, permanent oscilloscope, and WAV/MIDI/MusicXML recording.

Minimum requirements

Antitotem already has ready-made installers for Linux, Windows and macOS (see Download, at the top of the page). The requirements below cover both using one of those binaries and compiling from source.

System

Linux (tested on Debian/Ubuntu, amd64) — .deb package installed and opened for real. Windows (.exe) and macOS (.dmg): installers built and tested via CI on real runners, but not yet opened on real Windows/macOS hardware — see the note below.

To build

  • CMake ≥ 3.22
  • C++20 compiler (GCC/Clang)
  • Local checkout of JUCE
  • Audio device (ALSA/PipeWire)

To install the .deb

  • libasound2, libfontconfig1, libfreetype6
  • libx11-6, libxext6, libxss1
  • libgio-2.0-0, libstdc++6, libc6

Installation

1

Linux — .deb package

sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # if any dependency is missing

Once installed, run antitotem from a terminal, or look for "Antitotem - Objeto Sonoro" in your application menu.

2

Windows — .exe installer

Run the downloaded installer and follow the wizard. Built and tested via CI on a real Windows runner, but not yet opened on real Windows hardware — see the note below.

3

macOS — .dmg image

Open the downloaded .dmg and drag Antitotem into Applications. Built and tested via CI on a real macOS runner, but not yet opened on real macOS hardware — see the note below.

All three installers are built and tested via GitHub Actions; Windows and macOS haven't been opened on real hardware of those platforms yet. Full guide, with every detail and troubleshooting, in the INSTALL.md.

Build from source

An alternative for those who'd rather build it themselves than use the ready-made installers:

1

Get the code

git clone https://github.com/lucioaraujo/antitotem.git and enter the directory.

2

Build and run directly

Simplest path for immediate use — builds and opens the current version:

./run_antitotem.sh
3

Or build the .deb package yourself

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DANTITOTEM_JUCE_PATH=/path/to/JUCE
cmake --build build --target AntitotemSimpleSequencerApp -j
cd build && cpack -G DEB
sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # if any dependency is missing

Build requirements, core tests and troubleshooting in the INSTALL.md.

Objet Sonore

Instrument modulaire autonome JUCE/C++20, précurseur et parrain de la famille RASGO. Cinq oscillateurs, scanner 16 pas, ADSR, VCF multimode, bruits et S&H, retours, effets, mixeur, oscilloscope permanent et enregistrement WAV/MIDI/MusicXML.

Prérequis minimaux

Antitotem a déjà des installeurs prêts pour Linux, Windows et macOS (voir Télécharger, en haut de la page). Les prérequis ci-dessous couvrent aussi bien l'utilisation d'un de ces binaires que la compilation depuis les sources.

Système

Linux (testé sur Debian/Ubuntu, amd64) — paquet .deb installé et ouvert pour de vrai. Windows (.exe) et macOS (.dmg) : installeurs générés et testés via CI sur de vrais runners, mais pas encore ouverts sur un vrai Windows/macOS — voir la note ci-dessous.

Pour compiler

  • CMake ≥ 3.22
  • Compilateur C++20 (GCC/Clang)
  • Copie locale de JUCE
  • Périphérique audio (ALSA/PipeWire)

Pour installer le .deb

  • libasound2, libfontconfig1, libfreetype6
  • libx11-6, libxext6, libxss1
  • libgio-2.0-0, libstdc++6, libc6

Installation

1

Linux — paquet .deb

sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # si une dépendance manque

Une fois installé, lancez antitotem depuis un terminal, ou cherchez « Antitotem - Objeto Sonoro » dans votre menu d'applications.

2

Windows — installeur .exe

Lancez l'installeur téléchargé et suivez l'assistant. Généré et testé via CI sur un vrai runner Windows, mais pas encore ouvert sur un vrai Windows — voir la note ci-dessous.

3

macOS — image .dmg

Ouvrez le .dmg téléchargé et glissez Antitotem dans Applications. Généré et testé via CI sur un vrai runner macOS, mais pas encore ouvert sur un vrai macOS — voir la note ci-dessous.

Les trois installeurs sont générés et testés via GitHub Actions ; Windows et macOS n'ont pas encore été ouverts sur du vrai matériel de ces plateformes. Guide complet, avec tous les détails et le dépannage, dans le INSTALL.md.

Compiler depuis les sources

Une alternative pour celles et ceux qui préfèrent compiler plutôt qu'utiliser les installeurs prêts :

1

Récupérer le code

git clone https://github.com/lucioaraujo/antitotem.git puis entrez dans le répertoire.

2

Compiler et lancer directement

Le plus simple pour un usage immédiat — compile et ouvre la version actuelle :

./run_antitotem.sh
3

Ou générer le paquet .deb vous-même

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DANTITOTEM_JUCE_PATH=/chemin/vers/JUCE
cmake --build build --target AntitotemSimpleSequencerApp -j
cd build && cpack -G DEB
sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # si une dépendance manque

Prérequis de compilation, tests du core et dépannage dans le INSTALL.md.

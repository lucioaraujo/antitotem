Objeto Sonoro

Instrumento standalone JUCE/C++20, modular, precursor e patrono da família RASGO. Cinco osciladores, scanner de 16 etapas, ADSR, VCF multimodo, ruídos e S&H, retornos, efeitos, mixer, osciloscópio permanente e gravação WAV/MIDI/MusicXML.

Baixar

Versão v0.1.1 — escolha seu sistema; o download começa direto:

Linux pacote .deb (Ubuntu, Debian, Mint) Baixar → Linux AppImage (qualquer distribuição) Baixar → Linux .tar.gz (sem root) Baixar → Windows instalador .exe Baixar → Windows .zip portátil (sem instalar) Baixar → macOS imagem .dmg (Intel e Apple Silicon) Baixar →

Na primeira abertura, o Windows e o macOS mostram um aviso de segurança: o programa é livre e não tem certificado pago de assinatura. Não é defeito; o que clicar está em Instalação, logo abaixo. Todas as versões, inclusive as de teste: página de releases.

Requisitos mínimos

Sistema

Windows 10 ou 11, 64 bits · macOS 10.13+ (Intel) ou 11+ (Apple Silicon), um só pacote Universal 2 · Linux x86-64 com glibc 2.35+ (distribuições de 2022 em diante).

Computador (medido)

Num Intel Core i5-6500 (2015, 4 núcleos, 3,2 GHz): o app inteiro usa cerca de 60% de um núcleo; o motor de som sozinho, 10–11% a 44,1/48 kHz, no pior caso. Memória: cerca de 45 MB. Qualquer computador de 64 bits com dois núcleos e 4 GB basta; máquinas mais fracas não foram testadas.

Para compilar

  • CMake ≥ 3.22
  • Compilador C++20 (GCC/Clang)
  • Checkout local do JUCE
  • Dispositivo de áudio (ALSA/PipeWire)

O que o .deb pede

  • libasound2, libfontconfig1, libfreetype6
  • libx11-6, libxext6, libxss1
  • GLib (libglib2.0-0), libstdc++6, libc6

Instalação

1

Windows

  1. Abra o .exe. Aparece a janela azul "O Windows protegeu o computador": clique em "Mais informações" e depois em "Executar assim mesmo".
  2. Se pedir permissão de administrador, clique em "Sim".
  3. "Avançar" até o fim; a última tela já traz "Executar o Antitotem" marcado. Depois ele fica no Menu Iniciar e na área de trabalho.

Sem instalar: descompacte o .zip e abra Antitotem - Objeto Sonoro.exe. Se você ainda tem a v0.1.0 e ela não abre, instale o Visual C++ Redistributable da Microsoft — a partir da v0.1.1 isso não é mais necessário.

2

macOS

  1. Abra o .dmg e arraste o Antitotem para Aplicativos.
  2. Abra o app. O macOS avisa que não pode verificar o desenvolvedor: clique em "OK" (não em "Mover para o Lixo").
  3. Em Ajustes do Sistema → Privacidade e Segurança, clique em "Abrir Mesmo Assim", confirme com a senha e clique em "Abrir". Só na primeira vez. No macOS 14 ou anterior: botão direito no app → Abrir → Abrir.

Se a v0.1.0 disser que o app "está danificado": no Terminal, xattr -dr com.apple.quarantine "/Applications/Antitotem - Objeto Sonoro.app".

3

Linux

  • Ubuntu 22.04+, Debian 12+, Mint 21+: dois cliques no .deb, ou sudo apt install ./antitotem-0.1.1-Linux.deb.
  • Fedora, Arch, openSUSE e outras: o AppImage (marque como executável e abra) ou o .tar.gz (descompacte e rode ./install.sh, que instala no seu usuário, sem root).

Os três pacotes Linux são testados na abertura em Debian 12, Ubuntu 24.04, Fedora e Arch antes de cada versão.

Guia completo, com requisitos e solução de problemas, no INSTALL.md. Os pacotes de Windows e macOS são gerados e conferidos pela integração contínua (sem dependência do Visual C++; pacote macOS selado); ainda não foram abertos pelo autor em máquinas reais desses sistemas.

Compilar do código-fonte

Alternativa pra quem prefere compilar em vez de usar os instaladores prontos:

1

Obter o código

git clone https://github.com/lucioaraujo/antitotem.git e entre no diretório.

2

Compilar e rodar direto

Mais simples para uso imediato — compila e abre a versão atual:

./run_antitotem.sh
3

Ou gerar o pacote .deb você mesmo

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DANTITOTEM_JUCE_PATH=/caminho/para/JUCE
cmake --build build --target AntitotemSimpleSequencerApp -j
cd build && cpack -G DEB
sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # se faltar alguma dependência

Requisitos de build, testes do core e solução de problemas no INSTALL.md.

Objeto Sonoro

Instrumento standalone JUCE/C++20, modular, precursor e patrono da família RASGO. Cinco osciladores, scanner de 16 etapas, ADSR, VCF multimodo, ruídos e S&H, retornos, efeitos, mixer, osciloscópio permanente e gravação WAV/MIDI/MusicXML.

Requisitos mínimos

Antitotem já tem instaladores prontos pra Linux, Windows e macOS (veja Baixar, no topo da página). Os requisitos abaixo cobrem tanto usar um desses binários quanto compilar a partir do código-fonte.

Sistema

Linux (testado em Debian/Ubuntu, amd64) — pacote .deb instalado e aberto de verdade. Windows (.exe) e macOS (.dmg): instaladores gerados e testados via CI em runners reais, mas ainda não abertos num Windows/macOS de verdade — ver nota abaixo.

Para compilar

  • CMake ≥ 3.22
  • Compilador C++20 (GCC/Clang)
  • Checkout local do JUCE
  • Dispositivo de áudio (ALSA/PipeWire)

Para instalar o .deb

  • libasound2, libfontconfig1, libfreetype6
  • libx11-6, libxext6, libxss1
  • libgio-2.0-0, libstdc++6, libc6

Instalação

1

Linux — pacote .deb

sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # se faltar alguma dependência

Depois de instalado, rode antitotem no terminal, ou procure "Antitotem - Objeto Sonoro" no menu de aplicativos.

2

Windows — instalador .exe

Execute o instalador baixado e siga o assistente. Gerado e testado via CI num runner Windows real, mas ainda não aberto num Windows de verdade — ver nota abaixo.

3

macOS — imagem .dmg

Abra o .dmg baixado e arraste o Antitotem pra pasta Aplicativos. Gerado e testado via CI num runner macOS real, mas ainda não aberto num macOS de verdade — ver nota abaixo.

Todos os três instaladores são gerados e testados via GitHub Actions; Windows e macOS ainda não foram abertos em hardware de verdade dessas plataformas. Guia completo, com todos os detalhes e solução de problemas, no INSTALL.md.

Compilar do código-fonte

Alternativa pra quem prefere compilar em vez de usar os instaladores prontos:

1

Obter o código

git clone https://github.com/lucioaraujo/antitotem.git e entre no diretório.

2

Compilar e rodar direto

Mais simples para uso imediato — compila e abre a versão atual:

./run_antitotem.sh
3

Ou gerar o pacote .deb você mesmo

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DANTITOTEM_JUCE_PATH=/caminho/para/JUCE
cmake --build build --target AntitotemSimpleSequencerApp -j
cd build && cpack -G DEB
sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # se faltar alguma dependência

Requisitos de build, testes do core e solução de problemas no INSTALL.md.

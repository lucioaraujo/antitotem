Objeto Sonoro

Instrumento independiente JUCE/C++20, modular, precursor y patrono de la familia RASGO. Cinco osciladores, escáner de 16 pasos, ADSR, VCF multimodo, ruidos y S&H, retornos, efectos, mezclador, osciloscopio permanente y grabación WAV/MIDI/MusicXML.

Descargar

Versión v0.1.3 — elija su sistema; la descarga empieza directamente:

Linux paquete .deb (Ubuntu, Debian, Mint) Descargar → Linux AppImage (cualquier distribución) Descargar → Linux .tar.gz (sin root) Descargar → Windows instalador .exe Descargar → Windows .zip portátil (sin instalar) Descargar → macOS imagen .dmg (Intel y Apple Silicon) Descargar →

Si, en la primera apertura, Windows o macOS dice que el programa no pudo verificarse o que puede contener software malicioso (o muestra un mensaje parecido), no lo borre: siga los pasos de Instalación, más abajo, para autorizarlo. Todas las versiones, incluidas las de prueba: página de releases.

Requisitos mínimos

Sistema

Windows 10 u 11, 64 bits · macOS 10.13+ (Intel) u 11+ (Apple Silicon), un solo paquete Universal 2 · Linux x86-64 con glibc 2.35+ (distribuciones de 2022 en adelante).

Ordenador (medido)

En un Intel Core i5-6500 (2015, 4 núcleos, 3,2 GHz): la app entera usa cerca del 60% de un núcleo; el motor de sonido solo, 10–11% a 44,1/48 kHz, en el peor caso. Memoria: unos 45 MB. Cualquier ordenador de 64 bits con dos núcleos y 4 GB basta; máquinas más débiles no se han probado.

Para compilar

  • CMake ≥ 3.22
  • Compilador C++20 (GCC/Clang)
  • Un checkout local de JUCE
  • Un dispositivo de audio (ALSA/PipeWire)

Lo que pide el .deb

  • libasound2, libfontconfig1, libfreetype6
  • libx11-6, libxext6, libxss1
  • GLib (libglib2.0-0), libstdc++6, libc6

Instalación

1

Windows

  1. Abra el .exe. Aparece la ventana azul «Windows protegió su PC»: pulse «Más información» y luego «Ejecutar de todas formas».
  2. Si pide permiso de administrador, pulse «Sí».
  3. «Siguiente» hasta el final; la última pantalla ya trae «Ejecutar Antitotem» marcado. Después queda en el menú Inicio y en el escritorio.

Sin instalar: descomprima el .zip y abra Antitotem - Objeto Sonoro.exe. Si aún tiene la v0.1.0 y no abre, instale el Visual C++ Redistributable de Microsoft — desde la v0.1.1 ya no hace falta. Si el acceso directo del menú Inicio de la v0.1.0 o v0.1.1 no abre el programa, instale la versión más reciente encima. Si aparecen varias versiones instaladas, desinstale las antiguas en Configuración → Aplicaciones; desde la v0.1.3, cada versión nueva reemplaza a la anterior sola.

2

macOS

  1. Abra el .dmg y arrastre Antitotem a Aplicaciones.
  2. Abra la app. macOS la bloquea diciendo que Apple no pudo confirmar que esté libre de software malicioso — no es un defecto. Pulse «OK» (no «Trasladar a la papelera»).
  3. En Ajustes del Sistema → Privacidad y seguridad, pulse «Abrir igualmente», confirme con su contraseña y pulse «Abrir». Solo la primera vez. En macOS 14 o anterior: clic derecho en la app → Abrir → Abrir.

Si el botón no aparece o el bloqueo continúa, abra el Terminal (Aplicaciones → Utilidades), pegue xattr -dr com.apple.quarantine "/Applications/Antitotem - Objeto Sonoro.app" y pulse Intro; después abra la app normalmente. Esto también resuelve el «está dañada» de la v0.1.0.

Si aun así no abre, escriba a rasgo.instruments@gmail.com indicando la versión de macOS, el modelo del Mac y el mensaje que aparece.

3

Linux

  • Ubuntu 22.04+, Debian 12+, Mint 21+: doble clic en el .deb, o sudo apt install ./antitotem-0.1.3-Linux.deb.
  • Fedora, Arch, openSUSE y otras: el AppImage (márquelo como ejecutable y ábralo) o el .tar.gz (descomprima y ejecute ./install.sh, que instala para su usuario, sin root).

Los tres paquetes Linux se prueban al abrir en Debian 12, Ubuntu 24.04, Fedora y Arch antes de cada versión.

Guía completa, con requisitos y solución de problemas, en INSTALL.md (inglés y portugués).

Compilar desde el código fuente

Una alternativa para quien prefiere compilar en vez de usar los instaladores listos:

1

Obtener el código

git clone https://github.com/lucioaraujo/antitotem.git y entra en el directorio.

2

Compilar y ejecutar directamente

El camino más simple para uso inmediato — compila y abre la versión actual:

./run_antitotem.sh
3

O generar el paquete .deb tú mismo

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DANTITOTEM_JUCE_PATH=/ruta/a/JUCE
cmake --build build --target AntitotemSimpleSequencerApp -j
cd build && cpack -G DEB
sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # si falta alguna dependencia

Requisitos de compilación, tests del core y solución de problemas en el INSTALL.md.

Objet Sonore

Instrument modulaire autonome JUCE/C++20, précurseur et parrain de la famille RASGO. Cinq oscillateurs, scanner 16 pas, ADSR, VCF multimode, bruits et S&H, retours, effets, mixeur, oscilloscope permanent et enregistrement WAV/MIDI/MusicXML.

Prérequis minimaux

Antitotem s'exécute aujourd'hui depuis les sources ; aucun binaire n'est publié. Les prérequis ci-dessous couvrent aussi bien l'exécution d'un paquet .deb construit localement que la compilation depuis zéro.

Système

Linux (testé sur Debian/Ubuntu, amd64) — paquet .deb installé et ouvert pour de vrai. Windows et macOS : build et installeur déjà générés automatiquement via CI, mais pas encore ouverts sur un vrai Windows/macOS — voir la note ci-dessous.

Pour compiler

  • CMake ≥ 3.22
  • Compilateur C++20 (GCC/Clang)
  • Copie locale de JUCE
  • Périphérique audio (ALSA/PipeWire)

Pour installer le .deb

  • libasound2, libfontconfig1, libfreetype6
  • libx11-6, libxext6, libxss1
  • libgio-2.0-0, libstdc++6, libc6

Installation

1

Récupérer le code

git clone https://github.com/lucioaraujo/antitotem.git puis entrez dans le répertoire.

2

Compiler et lancer directement

Le plus simple pour un usage immédiat — compile et ouvre la version actuelle :

./run_antitotem.sh
3

Ou générer le paquet .deb

cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
  -DANTITOTEM_JUCE_PATH=/chemin/vers/JUCE
cmake --build build --target AntitotemSimpleSequencerApp -j
cd build && cpack -G DEB
sudo dpkg -i antitotem-0.1.0-Linux.deb
sudo apt-get install -f   # si une dépendance manque

Windows (NSIS/.exe) et macOS (DragNDrop/.dmg) : déjà disponibles au téléchargement dans la release antitotem-v0.1.0, aux côtés du .deb Linux — générés et testés via GitHub Actions sur de vrais runners Windows/macOS. Les installeurs compilent proprement, mais n'ont pas encore été ouverts sur un vrai Windows ou macOS (le dépôt est privé, le lien exige un compte GitHub avec accès). Guide complet, avec tous les détails et le dépannage, dans le INSTALL.md.

Provenance

Ce répertoire réunit le prototype numérique actuel et la documentation d'une recherche inspirée par la pratique matérielle de l'Antitotem original — instrument matériel auctorial, modulaire, CMOS/discret, construit en 2013. Le fonds historique reste séparé et n'est pas remplacé par ce code.
